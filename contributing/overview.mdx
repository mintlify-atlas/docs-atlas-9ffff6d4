WordPress Playground is an open-source project that welcomes contributors of all kinds. Whether you write code, improve documentation, triage issues, translate content, or share ideas, your contributions make the project better for everyone. All contributors are expected to follow the WordPress [Code of Conduct](https://make.wordpress.org/handbook/community-code-of-conduct/).

## How to get involved

The best places to connect with the Playground community are:

- **GitHub Issues** — [wordpress-playground](https://github.com/WordPress/wordpress-playground/issues) and [playground-tools](https://github.com/WordPress/playground-tools/issues) track all bugs and feature requests.
- **GitHub Discussions** — Use [Discussions](https://github.com/WordPress/wordpress-playground/discussions) for ideas, questions, and proposals that are not yet actionable issues.
- **WordPress Slack** — Join the [`#playground` channel](https://wordpress.slack.com/archives/C04EWKGDJ0K) on WordPress Slack for real-time conversation with contributors and maintainers.

## Triaging issues

Triaging is a great way to contribute without writing code. Here is how:

1. Browse [open issues](https://github.com/WordPress/wordpress-playground/issues?q=is%3Aopen+is%3Aissue) in the main repository, and the same list in [Playground Tools](https://github.com/WordPress/playground-tools/issues?q=is%3Aopen+is%3Aissue).
2. Read the description and existing comments.
3. If the issue is a reproducible bug, add a comment confirming it or propose a fix.
4. If you have relevant context or information, add a comment to help maintainers understand the issue better.
