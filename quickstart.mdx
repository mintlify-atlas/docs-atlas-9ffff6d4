---
title: "WordPress Playground quickstart: demo, CLI, and embed"
description: "Try the live demo, pre-install plugins via URL, run WordPress locally with the CLI, and embed a full WordPress instance in your app."
---

WordPress Playground gives you a full, isolated WordPress environment in seconds — no server, no Docker, no installation. This guide walks you through four ways to use it: the hosted website, Blueprint URLs, the CLI for local development, and the JavaScript API for embedding Playground in your own app.

<Steps>
  <Step title="Try the live demo">
    Open [playground.wordpress.net](https://playground.wordpress.net) in your browser. You get a fresh WordPress site immediately — no account or setup required.

    Every visit creates a new, isolated environment. Everything runs in your browser and is not sent anywhere. Close or refresh the tab to start over.

    <Tip>
      You can export your work at any time using **Site Manager → Download as .zip** before closing the tab.
    </Tip>
  </Step>

  <Step title="Install a plugin or theme via Blueprint URL">
    You can pre-install any plugin or theme from the WordPress.org directory by adding query parameters to the Playground URL. This is the [Query API](/developers/query-api).

    ```
    https://playground.wordpress.net/?plugin=coblocks
    https://playground.wordpress.net/?theme=pendant
    https://playground.wordpress.net/?plugin=coblocks&theme=pendant
    ```

    For more complex setup — installing multiple plugins, running PHP code, logging in automatically — use a Blueprint JSON file. Pass its URL with `blueprint-url`:

    ```
    https://playground.wordpress.net/?blueprint-url=https://example.com/my-blueprint.json
    ```

    A Blueprint describes a target WordPress state declaratively:

    ```json
    {
      "landingPage": "/wp-admin/",
      "preferredVersions": {
        "php": "8.2",
        "wp": "latest"
      },
      "steps": [
        {
          "step": "login",
          "username": "admin",
          "password": "password"
        },
        {
          "step": "installPlugin",
          "pluginData": {
            "resource": "wordpress.org/plugins",
            "slug": "friends"
          }
        }
      ]
    }
    ```

    See [Blueprints](/blueprints/overview) for the full reference, including all available steps.
  </Step>

  <Step title="Run locally with the CLI">
    The `@wp-playground/cli` package spins up a local WordPress environment in your terminal with a single command. No Docker or PHP installation needed.

    Navigate to your plugin or theme directory and run:

    ```bash
    npx @wp-playground/cli server --auto-mount
    ```

    The `--auto-mount` flag detects whether your project is a plugin or theme and mounts it automatically into the virtual WordPress environment. Playground opens in your browser and reloads as you make changes.

    You can also specify the PHP and WordPress versions:

    ```bash
    npx @wp-playground/cli server --auto-mount --php=8.2 --wp=6.5
    ```

    <Note>
      `--auto-mount` requires your project directory to contain a plugin or theme header. For manual mounting or Blueprint integration, see [Local development with the CLI](/local-development/cli).
    </Note>
  </Step>

  <Step title="Embed in your app with startPlaygroundWeb()">
    The `@wp-playground/client` package lets you embed a full WordPress instance inside an `<iframe>` in any web application. You load Playground's `remote.html` into the iframe and control it through the JavaScript API.

    Install the package:

    <CodeGroup>

    ```bash npm
    npm install @wp-playground/client
    ```

    ```bash yarn
    yarn add @wp-playground/client
    ```

    ```bash pnpm
    pnpm add @wp-playground/client
    ```

    </CodeGroup>

    Then set up an iframe and call `startPlaygroundWeb()`:

    ```html index.html
    <!DOCTYPE html>
    <iframe id="wp-playground" style="width: 1200px; height: 800px"></iframe>
    <script type="module">
      import { startPlaygroundWeb } from 'https://playground.wordpress.net/client/index.js';

      const client = await startPlaygroundWeb({
        iframe: document.getElementById('wp-playground'),
        remoteUrl: `https://playground.wordpress.net/remote.html`,
        blueprint: {
          landingPage: '/wp-admin/',
          preferredVersions: {
            php: '8.0',
            wp: 'latest',
          },
          steps: [
            {
              step: 'login',
              username: 'admin',
              password: 'password',
            },
            {
              step: 'installPlugin',
              pluginData: {
                resource: 'wordpress.org/plugins',
                slug: 'friends',
              },
            },
          ],
        },
      });

      const response = await client.run({
        // wp-load.php is only required if you want to interact with WordPress.
        code: '<?php require_once "/wordpress/wp-load.php"; $posts = get_posts(); echo "Post Title: " . $posts[0]->post_title;',
      });
      console.log(response.text);
    </script>
    ```

    `startPlaygroundWeb()` accepts a `blueprint` object inline, so you can configure WordPress — including the PHP version, plugins, themes, and initial content — entirely from JavaScript. The returned `client` object lets you run arbitrary PHP code, read and write files, and interact with WordPress programmatically.

    <Warning>
      The embed API is experimental and may change without notice. Pin to a specific version of `@wp-playground/client` to avoid unexpected breakage.
    </Warning>
  </Step>
</Steps>
