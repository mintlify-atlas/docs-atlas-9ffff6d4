WordPress Playground is a zero-setup WordPress environment that runs entirely in your browser using WebAssembly. There's no server to provision, no Docker to configure, and no installation process — just instant, isolated WordPress that you can use to build apps, test plugins and themes, create interactive demos, and run local development environments.

## How it works

WordPress Playground compiles PHP to WebAssembly using Emscripten, then runs the full WordPress stack — PHP, SQLite, and all — entirely client-side. The browser-based version uses an iframe-based isolation model where `@wp-playground/client` (parent window) communicates with `@wp-playground/remote` (inside the iframe) over a `postMessage` API.

## Get started

<Steps>
  <Step title="Try the live demo">
    Open [playground.wordpress.net](https://playground.wordpress.net) in your browser for an instant WordPress environment. No account required.
  </Step>
  <Step title="Install a plugin or theme">
    Use a Blueprint URL to open Playground with any WordPress.org plugin or theme pre-installed. See [Blueprints](/blueprints/overview) to learn how.
  </Step>
  <Step title="Set up local development">
    Run `npx @wp-playground/cli server --auto-mount` in your plugin or theme directory to start a local development server instantly.
  </Step>
  <Step title="Embed in your app">
    Install `@wp-playground/client` and call `startPlaygroundWeb()` to embed a full WordPress instance in your web application.
  </Step>
</Steps>

<Note>
  WordPress Playground is experimental software. The API is subject to change without notice. A stable API release is a future milestone as the codebase matures.
</Note>
